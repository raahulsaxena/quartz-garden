## What is Dynamic Programming?

Dynamic Programming (DP) is an algorithmic technique for solving optimization problems by breaking them down into overlapping subproblems and solving each subproblem just once, storing its result.

DP is ideal for problems exhibiting:
- Overlapping Subproblems: Recursive subproblems repeat.
- Optimal Substructure: Optimal solution can be constructed from optimal solutions of its subproblems.
